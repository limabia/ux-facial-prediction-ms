# FaceUX dataset

Facial expressions and self-reported user experience (UEQ-S) in digital game
sessions. 30 participants played three games (*TunelRush*, *CatsDrop*,
*PacMan*, always in this order) for 180 s each, totaling **90 sessions** and
**756,000 frames**. For each session the dataset provides the per-frame
probabilities of seven facial emotions (`face-api.js`), item-level UEQ-S
responses, mood (reduced POMS) before and after the session, demographic and
contextual controls, and window-aggregated features (1 to 20 windows).

The study was approved by the Research Ethics Committee of EACH–USP
(CAAE 38540620.0.0000.5390). Video recordings were discarded after processing,
as established in the informed consent form and the Brazilian General Data
Protection Law (LGPD); **no facial images are distributed**. Participants are
identified only by a sequential two-digit id (01–30).

This folder is generated by [`export_public_dataset.py`](../export_public_dataset.py)
from the anonymized files produced by [`anonymize_data.py`](../anonymize_data.py).

## Layout

The layout mirrors the `data/` folder expected by the pipeline in this
repository, so the code runs directly on it (see [Reproduction](#reproduction)).

```
dataset/
├── raw/
│   ├── controle-experimentos.csv                # 30 participants, controls
│   ├── ueq/UEQ-<Game>.csv                       # UEQ-S, one file per game
│   └── humor/<NN>-QuestionarioHumor-<Stage>.csv # POMS, 4 time points
├── interim/frames/
│   ├── <NN>-<Game>/expressions.csv              # 90 per-frame series
│   └── summary_max_nwindows<W>.csv              # W = 1..20, one row per session
└── SHA256SUMS
```

Categorical values and some file names are in Portuguese, as collected.

## Files

### `raw/controle-experimentos.csv` — one row per participant

| Column | Values |
|---|---|
| `id` | `01`–`30` |
| `data_realizacao` | collection month, `MM/YYYY` (day removed for privacy) |
| `sexo` | `masculino` (male), `feminino` (female) |
| `idade` | age as text, e.g. `26 anos` (= 26 years) |
| `formacao_academica` | `Ensino médio` (high school), `Ensino técnico` (technical school), `Graduação` (undergraduate), `Pós-graduação` (graduate) |
| `familiaridade_com_jogos` | self-reported familiarity with games: `alta` (high), `média` (medium), `baixa` (low) |
| `usa_oculos` | wears eyeglasses: `sim` (yes), `nao` (no) |

### `raw/ueq/UEQ-<Game>.csv` — one row per participant

`idPessoa`, `PUEQ1`–`PUEQ8`: UEQ-S items on the raw 1–7 scale (not recoded to
−3..+3). Items 1–4 form pragmatic quality and items 5–8 hedonic quality. The
questionnaire was administered in Portuguese.

| Item | Pair (1 – 7) | Item | Pair (1 – 7) |
|---|---|---|---|
| PUEQ1 | obstructive – supportive | PUEQ5 | boring – exciting |
| PUEQ2 | complicated – easy | PUEQ6 | not interesting – interesting |
| PUEQ3 | inefficient – efficient | PUEQ7 | conventional – inventive |
| PUEQ4 | confusing – clear | PUEQ8 | usual – leading edge |

### `raw/humor/<NN>-QuestionarioHumor-<Stage>.csv` — one row per participant

`idPessoa`, `PH1`–`PH7`: reduced POMS, 1 = negative pole, 7 = positive pole.

| Item | Pair (1 – 7) | Item | Pair (1 – 7) |
|---|---|---|---|
| PH1 | tired – rested | PH5 | discouraged – lively |
| PH2 | irritated – at ease | PH6 | impatient – patient |
| PH3 | sad – cheerful | PH7 | anxious – calm |
| PH4 | bad-tempered – good-tempered | | |

| File | Time point | Pre-session for | Post-session for |
|---|---|---|---|
| `01-QuestionarioHumor-inicial.csv` | before the first game | TunelRush | — |
| `02-QuestionarioHumor-tunelCats.csv` | after TunelRush | CatsDrop | TunelRush |
| `03-QuestionarioHumor-catsPacman.csv` | after CatsDrop | PacMan | CatsDrop |
| `04-QuestionarioHumor-final.csv` | after PacMan | — | PacMan |

### `interim/frames/<NN>-<Game>/expressions.csv` — one row per frame

`frame` (`frame_0000`, …) and the probabilities of `neutral`, `happy`, `sad`,
`angry`, `fearful`, `disgusted`, `surprised` (they sum to 1). Only the first
180 s of each session are included: 10,800 frames for the 50 sessions recorded
at 60 fps and 5,400 for the 40 recorded at 30 fps.

Frames without a valid face detection (SSD MobileNet v1, confidence < 0.5)
were imputed as `neutral = 1.0` and all other emotions `= 0`. They can be
identified by `neutral == 1.0` (21,310 frames, 2.82%). Imputation is
concentrated in participant 15 (28.7%, 30.2% and 75.8% of the frames in
CatsDrop, TunelRush and PacMan).

### `interim/frames/summary_max_nwindows<W>.csv` — one row per session

Each session is split into `W` equal windows. Columns:

- `idPessoa` (integer, not zero-padded), `jogo` (game);
- `PUEQ1`–`PUEQ8` for that game;
- `PHA1`–`PHA7` and `PHD1`–`PHD7`: mood before (*antes*) and after (*depois*)
  that game, following the table above;
- the control columns listed above;
- `<emotion>_<stat>_w<NN>`: emotion aggregated in window `NN` (`01`..`W`),
  with `stat` ∈ {`max`, `mean`, `std`, `p25`, `p50`, `p75`, `p90`, `p95`};
- `<emotion><N>` (e.g. `happy1`): legacy column, identical to
  `<emotion>_max_w<NN>`.

`W = 1` has 93 columns and `W = 20` has 1,290.

## Notes for reuse

- **Participant 21** gave the same overall UEQ-S score (6.75) to the three
  games, with zero variance. The record is kept here; it was excluded from the
  prediction experiments of the associated paper (87 sessions, 29 participants).
- **Validate by participant.** Each participant contributes three sessions;
  use grouped splits (e.g. Leave-One-Subject-Out) to avoid identity leakage.
- **Game order is fixed** (TunelRush → CatsDrop → PacMan), so game and time
  in the protocol are confounded.
- The game identifier is spelled `TunelRush` in all files.

## Reproduction

From the repository root, regenerate the window summaries from the per-frame
files (the script also writes `W = 21..40`):

```bash
DATA_RAW_DIR=dataset/raw DATA_INTERIM_DIR=dataset/interim/frames \
    python expressions_csv_exporter/build_dataset_by_windows.py
```

Check file integrity with `shasum -a 256 -c SHA256SUMS` (inside `dataset/`).
